14. MATCHING WEIGHTS
==================================================

Default weights:

Position compatibility = 30%

Distance / region = 15%

Playing level = 20%

Player score / attributes = 20%

Availability overlap = 10%

Visibility / boost = 5%

Total = 100%

Store weights in Firestore.

Example:

matchingConfig/default

{
  positionWeight: 0.30,
  distanceWeight: 0.15,
  levelWeight: 0.20,
  attributesWeight: 0.20,
  availabilityWeight: 0.10,
  boostWeight: 0.05,
  version: 1
}

Every configuration change must create a new version.

==================================================
15. MATCHING CALCULATIONS
==================================================

Position:

exact match = 1.0
adjacent position = 0.5
incompatible = 0

Distance:

use a deterministic decay function based on club preferred radius.

Playing level:

normalize player level against club target tier.

Attributes:

weighted average of relevant attributes.

Availability:

calculate overlap between player and club training/trial availability.

Boost:

flat bonus while active.

Final:

score =
positionScore * positionWeight +
distanceScore * distanceWeight +
levelScore * levelWeight +
attributeScore * attributeWeight +
availabilityScore * availabilityWeight +
boostScore * boostWeight

Clamp result between 0 and 1.

Store score breakdown.
